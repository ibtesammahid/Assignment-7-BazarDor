# Bazardor (বাজার দর)

> **A simple market price tracking platform for Bangladesh.**

## Short Description

Bazardor is a Bengali-language web application that helps users explore daily prices of essential products across Bangladesh. Users can browse products by category, view product details, compare historical prices, and check price ranges across different markets to make informed shopping decisions.

## Technologies Used

- **Next.js 16** — React framework
- **React** — User interface
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Styling and responsive layouts
- **Better Auth** — User authentication
- **MongoDB** — Database
- **Programming Hero API** — Product and category data
- **Noto Serif Bengali** — Bengali typography
- **React Icons** — Icons
- **Git & GitHub** — Version control

## 5 Key Features

1. **Daily Market Prices** — Browse prices of essential products such as rice, lentils, vegetables, fish, and meat.
2. **Category-Based Browsing** — Find products through organized categories.
3. **Product Details** — View product information, units, and current pricing.
4. **Historical Price Comparison** — Compare today's prices with yesterday's, last week's, and last month's prices.
5. **Market-Wise Price Ranges** — Check minimum and maximum prices across listed markets and divisions.
